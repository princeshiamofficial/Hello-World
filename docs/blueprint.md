# **App Name**: Hello Canvas

## Core Features:

- Display Greeting: Show a default 'Hello, World!' greeting on the page.
- Personalized Input: Allow the user to input their name, updating the greeting dynamically to 'Hello, [Name]!'.

## Style Guidelines:

- The chosen light color scheme is inspired by the themes of simplicity and clarity, evoking a welcoming and calming user experience. The primary color is a soft, inviting blue (#4DA6E6), symbolizing friendliness and openness.
- The background color, a very light blue (#E8F0F6), is designed to provide a clean and airy canvas, visibly echoing the primary hue while maintaining high contrast for readability.
- The accent color is a tranquil blue-green (#1FA8A8), chosen for its analogous relationship to the primary color and its distinct saturation and brightness, creating focal points without overwhelming the user.
- The application will use 'Inter' (sans-serif) for all text. Its neutral and modern design ensures legibility and maintains the app's minimalist aesthetic, suitable for both headlines and short body text.
- Use minimalist, line-art style icons where necessary, prioritizing clarity and directness over decorative complexity.
- A clean and centered layout ensures that the greeting and input field are the primary focus, facilitating an intuitive and straightforward user interaction.
- Subtle, smooth transition animations for changes in greeting text or input field focus, enhancing the feeling of responsiveness and fluidity.
